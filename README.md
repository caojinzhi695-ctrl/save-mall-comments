# save-mall-comments

Codex skill for Chinese IP poster and board workflows, including the current default "分块图片" process:

1. Save 4 module-complete block images.
2. Process each block one by one in ChatGPT, generating 2 images per block.
3. Create a clean final Desktop delivery folder with outputs, conversation records, and backups.

See `SKILL.md` for the full workflow and `INSTALL.md` for installation instructions.
